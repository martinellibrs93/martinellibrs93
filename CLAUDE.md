# CLAUDE.md

Guidance for Claude Code (claude.ai/code) when working in this repository.

## What this repository is

`martinellibrs93/martinellibrs93` is a **GitHub profile repository** — the special
repo whose name matches its owner's username. GitHub renders `README.md` from this
repo's default branch at the top of https://github.com/martinellibrs93.

Default branch: `main`. Topics: `config`, `github-config`.

## Current state

Two files, both at the root:

- `README.md` — the profile README that renders on the GitHub profile page
- `CLAUDE.md` — this file

There is no application code, build system, test suite or CI here, and there
should not be. A profile repo needs `README.md` and little else.

## What the README says, and why

It presents André Martinelli: a self-taught builder who ships production software
by directing AI coding agents. Three things carry it:

1. **Nest Reef** (nestreef.com) — a marine-aquarium platform he designed, built and
   operates. The repository is **private and stays private**: it is a commercial
   product with integration credentials in its history. The README instead lists
   measured figures (73 API routes, 363 automated tests, 49 additive migrations,
   273 merged pull requests, zero runtime dependencies) and offers read access on
   request.
2. **[job-collector](https://github.com/martinellibrs93/job-collector)** — the
   public repository that backs the claim: 81 tests, verified by mutation, with the
   reasoning for each design decision written down.
3. **Twelve years in specialty coffee**, including the Brazilian Latte Art
   Championship (2014) and 9th at the world championship. It stays in because for
   someone changing careers it answers the unspoken question — whether this person
   can take something from zero to the top of it.

## Rules for editing the README

- **Never add a number that has not been measured.** Every figure in it came from
  counting the real repository. If one changes, change it here rather than
  rounding up.
- **Do not claim users or traction for Nest Reef.** It is in closed beta with ten
  invites. Saying otherwise breaks in the first technical interview.
- **Do not describe him as having a computing degree or prior developer
  employment.** He has neither, the README says so plainly, and that honesty is
  what makes the rest credible.
- Keep it in English. The audience is recruiters and engineers in Ireland and the
  EU.

## Mechanics worth remembering

- The README must be named `README.md`, live at the **root of the default branch**,
  and the repo must be **public** — otherwise GitHub will not render it on the
  profile.
- Private contributions are set to show on the profile, so the contribution graph
  reflects work in private repositories without revealing their names.
